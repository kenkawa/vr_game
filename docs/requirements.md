# VRシューティング 要件まとめ(2026-09-21 時点)

Ken から伝えられた要望と、そこから決めた仕様を整理したものです。「Ken の要望」と「Claude が仮置きした値」を分けて書いています。仮置きの値は、実機で試してから調整する前提です。

## 1. ゲームの概要

- 一人称視点のVRシューティング
- 対象機種:Meta Quest 2 128GB
- 開発:Unity 6(6000.6.2f1)、Meta XR SDK 205.0、Mac mini(M4)
- 状況設定:プレイヤーは砦(とりで)の上に立って銃を構える。砦に向かって、地上と空中から敵が侵攻してくる。それを撃ち落として、砦を守る
- ステージ制(R34):ステージ 1 は砦(正面から敵が来る)、ステージ 2 は高い塔(全方向 360 度から敵に囲まれる)。各ステージの 5 ウェーブをすべて全滅させるとクリアして、自動で次へ進む
- v1の遊び方:その場で立って撃つ(アリーナ型)。座ってのプレイにも対応する(頭の高さを自動で補正する)。マルチプレイとストーリーは、v1ではやらない

## 3. 仕様の詳細

### 3.1 Ken が選んだこと

R5〜R7 について、次の選択肢を Ken が選びました。

- 両手撃ちの条件:両手を近づけて、両方のトリガーを引く(手の位置は問う。トリガーの同時押しだけでは発動しない)
- 残弾:両手で共有する(銃ごとに別々にはしない)
- アイテムの取得方法:自動で吸い寄せられる(倒した位置から、プレイヤーに向かって飛んでくる)
- グレード:両手で共通(片方だけ上がることはない)

R8〜R11 について、次の選択肢を Ken が選びました。

- ゲームオーバーの条件:砦に耐久値がある
- 敵の攻撃方法:近接のみ
- 砦や周囲の見た目:標準の立体で簡易に作る
- 世界観:中世ファンタジー(地上はゴブリン、空中はコウモリのような敵)

Editor の確認方法について、Meta XR Simulator(公式のヘッドセットなしの確認ツール。Mac の Apple シリコンに対応)を提案しました。Ken は、「くっついて見えるのはシミュレーター特有の問題なら、問題ない」と回答しています。

### 3.2 Claude が仮置きした値(実機で調整する)

すべて、Unity の Inspector から変更できます(砦・敵・ウェーブの値は、`Game` オブジェクトの `WaveSpawner`)。

**ため撃ち(GunSystem)**

- 威力:すぐ離すと 1、1.2 秒引き続けると最大の 5(その間は比例して増える)
- 撃ったあと、次のチャージを始められるまで 0.15 秒
- 弾は、銃口の向きへ、即座に届く方式(弾道の遅れはない)。射程は 120m
- 撃つと、その威力の大きさに応じて、コントローラーが震える。チャージ中も弱く震える
- チャージ中は、銃身の上のバーが伸び、照準線が太くオレンジになる

**弾の見た目(ShotEffects)**

- 撃った瞬間に、銃口が光る
- 銃口から着弾点まで、光の線(弾道)が引かれる。約 0.5 秒かけて細くなって消える
- 光の弾が、秒速 120m で、その線の上を飛んでいく
- 当たった場所が光る
- チャージが大きいほど、線も弾も太く、長く、オレンジ色になる。遠く(最大 60m)へ撃つほど、最大 3 倍まで太くする
- 両手撃ちの弾は、水色の太い線で、同じように 0.5 秒かけて消える

**両手撃ち(GunSystem)**

- 2 丁の銃(コントローラー)の中心どうしの実際の距離が 12cm 以内、つまり、手がくっついているくらいのときに成立する(コントローラーを左右でくっつけると、中心は約 8〜12cm 離れる想定)。トリガーを離した直後 0.15 秒は、判定を保つ(手がずれて撃ち損ねないように)
- 威力は、「2 丁ぶんの威力の合計 × 1.5」
- 残弾を 2 発ぶん使う。残弾が 1 発だけのときは、チャージの大きいほうの 1 丁だけで撃つ
- 弾は太く(半径 6cm)、当たりやすい
- 両手撃ちの状態になると、両方の銃の照準線が水色になる

**武器の切り替え(R31、R32 で合図を変更。`SkyPointDetector.cs` と GunSystem の `UpdateSkyPoint` / `ToggleWeapon`)**

- 左右の手ごとに、「銃口を頭上へ向ける」動作を見つけて、その手の武器を「銃 ⇄ バズーカ」で切り替える。もう一方の手には影響しない(両手ともバズーカにもできる)
- 判定:銃口の向きが、水平から **60 度以上**上を向き(`skySwitchAngle`。90 が真上)、その状態が **0.1 秒**続く(`skySwitchHold`)と、切り替わる(R33 で、65 度・0.35 秒から変更)
- 切り替えたあとは、銃口が **40 度より下**へ下がる(`skySwitchResetPitch`)まで、次の切り替えを受け付けない(上へ向けたままで、行ったり来たりしないため)。同じ手では、切り替えから 0.7 秒あける(`switchCooldown`)
- トリガーを引いている間は無効(空の敵を狙って撃つときに、切り替わらないため)。トリガーを引いたまま切り替わった場合は、一度離すまで撃てない
- 切り替えの表現:武器の見た目が「ぽん」と大きくなって落ち着く(0.25 秒)、「BAZOOKA」または「GUN」の文字、金属が噛み合う音(バズーカへは低く、銃へは高く)、コントローラーの短い振動、輪の火花
- 設定は、Inspector の `GunSystem` の「武器の切り替え(銃口を頭上へ向ける)」で調整できる。誤作動が多いときは、`skySwitchAngle` を上げるか、`skySwitchHold` を長くする(0.2 くらい)。切り替わりにくいときは、`skySwitchAngle` を下げる(50 くらい)。`skySwitchHold` は 0 にすると、向けた瞬間に切り替わる(`skySwitchEnabled` をオフにすると、この切り替えをしない)
- R31 のパンチでの切り替えは、Ken が「切り替えにくかった」ため、やめた
- 両手が銃のときだけ、両手を合わせた「合体(LINK)」と両手撃ちが使える。どちらかがバズーカだと、合体は解除される

**バズーカ(R31。`Bazooka.cs` と GunSystem の `TryFireBazooka`)**

- トリガーを引いた**瞬間**に 1 発撃つ(ため撃ちなし)。押しっぱなしでは連射しない。**発射間隔は 1.5 秒**(`bazookaFireInterval`)
- 弾は、銃口から 45m/秒(`rocketSpeed`)でまっすぐ飛ぶ(重力なし)。何も当たらず、敵の近くも通らずに 120m 飛ぶと、爆発せずに消える
- 爆発は、**半径 3.5m**(`bazookaRadius`)の敵にダメージ。基本の威力は **12**(`bazookaDamage`)に、グレードの倍率(1 + 0.3 × (グレード − 1))をかけた値。中心から半径の 30% までは全力、そこから端へ向けて弱くなり、端では 50%(R32 で 35% から上げた)。頭の判定(ヘッドショットの一撃)は使わない
- 爆発する条件(R32):
  - 何かに当たったとき(敵、地面、砦の壁など。柵は、当たり判定がなく、通り抜ける)。爆発の中心は、当たった面の外側 0.4m(地面なら、少し上)。地面に当たった場合も、まわりの敵にダメージが入る
  - **近接信管**:敵に当たらなくても、敵の 1.5m 以内(`bazookaProximity`。0 にすると無効)を通ったら、その場で爆発する。撃ってから 2.5m 飛ぶまでは働かない(手元の近くで、空の敵などに反応しないため)
  - 目安:ふつうの敵(体力 3)・空の敵(2)・走る敵(1.5)は、ほぼ範囲内なら倒れる。頑丈な敵(9)は 1〜2 発、巨大な敵(30)は 3 発前後
- **残弾は両手で共有**。1 発で **2 発ぶん**減る(`bazookaAmmoCost`)。足りないときは「NO AMMO」
- 見た目:太い鉄の筒、金の帯 3 本(まん中の 1 本はグレードの色)、筒の先の赤い弾頭、前後の持ち手、照準。上に光る宝石があり、撃った直後は暗く、次を撃てるまでに明るくなり、準備ができると脈打つ。照準の線は、準備できているとオレンジ、装填中は暗い茶色
- 弾の見た目:白い本体、赤い先端、後ろに揺れる炎と煙の跡。爆発:大きな火の玉がふくらんでしぼみ、火花、破片、地面の衝撃波の輪、昇る煙、重い爆発音、ごく短いスローモーション、コントローラーの振動
- 銃口の位置は、銃のときより前(バズーカの筒の先)。銃・バズーカのどちらでも、手元の文字に残弾とグレードが出る(バズーカのときは「BAZOOKA」の行も出る)

**ステージ制(R34。`WaveSpawner.cs` の `RunGame` / `RunStage` / `GoToTower` / `GameClear`)**

- 各ステージは、**5 ウェーブ**(`wavesToClear`)をすべて全滅させるとクリア。ステージ 1 = 砦、ステージ 2 = 塔。ステージ 2 をクリアするとゲームクリア(`includeTowerStage` をオフにすると、ステージ 1 のクリアでゲームクリア)
- ステージ 1 をクリアすると、自動で次へ進む:"STAGE 1 CLEAR!" の表示とファンファーレ → 4 秒(`stageClearSeconds`)→ 視界が一瞬真っ黒になる間に、砦を片付けて塔を作る → "STAGE 2 GET READY" → ウェーブ開始
- **残弾・グレード・スコアは、ステージをまたいで持ち越す**。塔の耐久値は、あらためて満タン(`towerMaxHealth` 120)から始まる
- **難易度は、ウェーブの通し番号**(ステージ 1 が 1〜5、ステージ 2 が 6〜10)で上がり続ける。ステージ 2 の最初のウェーブは、敵 13 体、大きさ 95%、速さ 1.25 倍、体力 1.4 倍。最後(10)は、敵 21 体、大きさ 75%、速さ 1.45 倍、体力 1.72 倍。巨大な敵は、通し番号 4、6、8、10 に出る
- 画面の文字は "STAGE 1  WAVE 3/5"、砦または塔の耐久値("FORT 90/100" や "TOWER 120/120")、スコア。ゲームオーバーでは "STAGE 2  WAVE 3" のように、どこで負けたかを出す。やり直しは、両方のトリガーを 1 秒引き続けて、**ステージ 1 から**
- 確認用:Inspector の `WaveSpawner` の `startAtStage` を **2** にすると、ステージ 1 を遊ばずに、塔から始まる(ふだんは 1 に戻す)

**塔(ステージ 2。`Tower.cs`)**

- プレイヤーは、高さ **12m**(`towerHeightMeters`)の塔の頂上の、丸い足場(半径 **0.9m**、`towerPlatformRadius`。R40 で、1.6m から狭くした)の真ん中に立つ。足場のふちには、何も立てない(R39 で、手すり・旗ざお・かがり火をなくした。床に金の細い線があるだけ。下の敵が見える)。耐久値は **120**(`towerMaxHealth`)
- 頂上の足場には、手すり、旗ざお、かがり火を置かない(R39)。旗ざお 4 本(赤い旗が風で揺れる)は、外柵の輪の上に立てた(敵の通り道の間。高さ約 4.6m、旗は 2 倍の大きさ)
- 塔の胴は、4 段の石のレンガ(下から高さ 3.5 / 3.5 / 3 / 1.75m、半径の上限 3.4 / 2.6 / 1.95 / 1.3m。足場が狭いときは、上の段ほど、もっと細くなる。足場 0.9m のときは、3.4 / 2.6 / 1.86 / 0.85m)。上の段ほど細くして、足場のふちの上を通る視線(下へ向かって外へ広がる円すい)の外へ、胴がはみ出さないようにしてある(はみ出すと、塔の足元の地面が見えなくなる)。段の境目に明るい石の帯、頂上の足元に金と赤の絨毯の模様と、ふちの金の線。麓に、門、たいまつ、赤いバナー 4 枚、矢を撃つ細い窓
- **敵は 360 度に広がるが、いきなりは囲まない(R35)**。敵が来る範囲(正面から左右へ何度まで)は、塔のステージの WAVE 1 から WAVE 5 へ、均等に広がる:

  - 範囲は `towerOpeningHalfAngle`(最初の範囲、既定 45)と `towerSurroundWave`(全方向になるウェーブ、既定 5)で決まる。`towerSurroundWave` を 6 以上にすると、もっとゆっくり広がる。1 にすると、最初から全方向
  - 地上の敵:塔を中心にした **24 本の道**(15 度おき。正面が 0 度)のうち、今のウェーブの範囲の中の道のどれかに沿って、90〜120m 先から歩いてくる。道はランダムに割り当て、あふれたら 2 列目(1.2m 外)に並ぶ。範囲が狭い WAVE 1 は、使える道が 7 本だけなので、2 列目に並びやすい
  - 空の敵:頂上のまわり(塔の中心軸から半径 3.2〜5m、`towerFlyMinRadius` / `towerFlyMaxRadius`)の、今のウェーブの範囲の中のどこかへ飛んできて、羽ばたきながら襲う
  - 画面の 3 行目に、今の範囲("ARC 90deg"。全方向は "ALL SIDES")を出す。ウェーブクリアのときは、次の予告("NEXT: ENEMIES SPREAD WIDER" / 最後の 1 つ前は "NEXT: ENEMIES FROM ALL SIDES!")を出す
  - 方向マーカーは、視界(正面から左右 48 度)の外に敵がいるときだけ出る。WAVE 1 は正面(左右 45 度)だけなので、ほとんど出ず、WAVE 2 から左右に出はじめ、後ろは WAVE 3〜4 から出る
- **外柵**(木の柵の輪。半径 **15.5m**、`towerFenceRadius`。高さ **0.5m**、`towerFenceHeight`。R36 で、視界をさえぎらないように低くした):地上の敵は、柵の外側で止まって、柵と塔を攻撃する(塔の耐久値が減る)。柵を塔の足元ではなく遠くに置いた理由:頂上の真ん中に立つと、足場のふちに隠れて、塔の足元に近い地面は見えない(見えはじめる距離は、足場の半径の約 8.5 倍。半径 0.9m なら約 7.7m、以前の 1.6m なら約 13.6m。R40 で足場を狭くしたので、柵はもっと近くに置ける)。柵を、見え始める距離の外に置くことで、敵が柵で止まったときに、頭を少し下へ向けるだけで、全員が見えて撃てる
- 周りの景色は、全方向に、敵の道を避けて置く(山、森、岩、茂み、草、光る水晶。`Scenery.BuildRing`)。地面には当たり判定があり、弾やバズーカが当たる
- **不具合の修正(R34 で発覚)**:砦の地面(`Fort.cs` の Ground)には、これまで当たり判定がなかった。そのため、地面を狙った弾やバズーカは地面を突き抜けていて、R32 の「地面で爆発してまわりの敵にダメージ」は、実際には働いていなかった。砦と塔の両方の地面に当たり判定を付けたので、直っているはず(実機で要確認)

**敵の方向マーカー(R34。`EnemyRadar.cs`。塔のステージだけ)**

- 視界の外の敵を、視界の端の小さな矢印で知らせる:**左の端**(左 38 度の方向。矢印は左向き)、**右の端**、**下の中央**("BACK x3" のように、真後ろの敵の数)
- 頭の向きから左右 48 度の外にいる敵を数える(頭の向きから 135 度以上は「真後ろ」)。塔から 45m 以内の敵だけ。矢印のとなりの数字は、その方向の敵の数
- 色は、いちばん近い敵の距離で変わる:20m 未満は赤(大きく脈打つ)、32m 未満はオレンジ、それより遠いと黄色。頭(カメラ)の子なので、頭を動かしても視界の同じ位置に出る
- `WaveSpawner` の `showEnemyMarkers` で、オン / オフできる。ゲームオーバーとゲームクリアのときは消える

**敵の見つけやすさ(R37。`Enemy.cs` の色と `AddGroundRing`、`Fort.cs` / `Tower.cs` の `GroundBrightness`)**

- 原因:地面(緑の草の模様)と、ふつうのゴブリンの肌(緑)が、色も明るさも近く、特に上から見下ろす砦・塔では、敵が地面に溶けて見えた
- 対策 1(地面):地面の草の模様と、土の道・輪に、`groundBrightness`(既定 0.65)をかけて暗くする。明るい色の敵との明るさの差を広げる。世界の雰囲気を変えたくないときは、1 に近づける(0.8 くらい)。もっと目立たせたいときは、0.5 くらいまで下げる
- 対策 2(敵の色):ふつうの肌 (0.50, 0.80, 0.32)、影の部分 (0.36, 0.62, 0.24)。オーガの肌 (0.80, 0.60, 0.42)。俊敏な敵の肌 (0.85, 0.95, 0.30)。コウモリの毛 (0.38, 0.24, 0.46)、翼 (0.56, 0.32, 0.64)。目は、これまでどおり光る(1 を超える色)
- 対策 3(足元の輪):地上の敵の足元に、赤みのあるオレンジの光る輪(色 (2.6, 0.5, 0.25)。1 を超える色で光って見せる。半径 0.62〜0.8m。敵の大きさに合わせて拡大・縮小)を付ける。出現時に敵と一緒に大きくなり、攻撃を受けると敵と一緒に白く光る。`enemyGroundRing` をオフにすると、出さない。空の敵には付けない(空を背景にしているときは見やすいため)
- 色の見え方は、コードだけでは確かめられないので、実機で見ながら調整する。輪が派手すぎるときは、`Enemy.cs` の `AddGroundRing` の色を暗くするか、オフにする

**残弾(GunSystem)**

- 初期は 24 発、最大は 40 発
- 1 発撃つごとに 1 発減る。アイテム 1 個で 8 発回復する
- 詰まらないようにする決まり:
  - ウェーブが始まるとき、残弾が 10 発より少なければ、10 発まで補充する
  - 残弾が 0 のときは、3 秒ごとに 1 発だけ回復する
  - 残弾が 6 発以下のときに敵を倒すと、必ず残弾回復アイテムが出る

**グレード(GunSystem)**

- グレードは 1〜5。1 上がるごとに、威力が 30% 増える
- 銃身の色:1 が灰、2 が緑、3 が青、4 が紫、5 が金
- 最大グレードのときにグレードアップ品を取ると、残弾が回復する

**アイテムのドロップ**

- 敵を倒したときに、グレードアップ(金色の箱)が 35%、残弾回復(緑のカプセル)が 45%、何も出ないのが残りの 20%
- 頑丈な敵と巨大な敵は、上の抽選とは別に、決まった数のアイテムを必ず追加で落とす(グレードアップ → 残弾回復 の順)
- アイテムは、敵の胸の高さ(空中の敵はその位置)から、0.4 秒ほど浮かんだあと、プレイヤーの胸のあたりへ向かって加速しながら飛び、近づくと取得される。30 秒たつと消える

**砦と周囲(Fort)**

- 砦の高さは 6m(Inspector の `Fort Height Meters` で変更できる)。プレイヤーは、その上面(城壁の通路)の中央に立つ
- 砦の幅は約 9.6m。四隅に塔、正面の壁に木の門、左右と後ろに胸壁がある。正面は、真下の敵が見えて撃てるように、低い壁にしてある
- 外柵(木の柵)が、砦の壁の 3.5m 手前に、横一列に立っている(R38 で、視界と弾をさえぎらないように、高さ 0.8m の低い柵に変えた。当たり判定なし。`fortFenceHeight`)。地上の敵は、この柵の前で止まって、柵と砦を攻撃する
- 周囲に、木が 40 本立っている(高さの目安)。配置は毎回同じで、敵の通り道と道は避けてある
- 耐久値は 100。敵が攻撃するたびに減る。減ったとき、砦と外柵が一瞬赤くなり、コントローラーが震える
- ウェーブをクリアするたびに、耐久値が 10 回復する
- 耐久値が 0 になるとゲームオーバー。画面に GAME OVER が出て、両方のトリガーを 1 秒引き続けると、最初からやり直す

**敵(Enemy / Target)**

すべて近接攻撃です。体力は、ウェーブごとに 8% ずつ、速さは 5% ずつ増えます。

| 敵 | 見た目 | 体力 | 速さ(m/秒) | 攻撃(砦へのダメージ / 間隔) | 得点 | 大きさ | 追加ドロップ |
|---|---|---|---|---|---|---|---|
| ゴブリン(地上・標準) | 緑の体、とがった耳、棍棒 | 3 | 2.5 | 3 / 1.6 秒 | 10 | 1 倍 | なし |
| 頑丈(鎧のゴブリン) | 兜、鎧、肩当て、盾。頭の上に体力バー | 9 | 1.6 | 4 / 1.8 秒 | 30 | 1.15 倍 | 1 個 |
| 巨大(オーガ) | 茶色の体、角、牙、大きなおなか。頭の上に体力バー | 30 | 1.0 | 12 / 2.5 秒 | 100 | 2.4 倍 | 2 個 |
| 俊敏(バンダナのゴブリン) | 黄緑の体、赤いバンダナ | 1.5 | 5.5 | 2 / 1.0 秒 | 20 | 0.7 倍 | なし |
| コウモリ(空中) | 紫の体、羽ばたく翼、赤い目、牙 | 2 | 5 | 2 / 2 秒(急降下) | 15 | 1 倍 | なし |

- 見た目は、標準の立体(球、カプセル、円柱、箱)を組み合わせて作る
- 敵の大きさは、上の表の倍率に、ウェーブごとの大きさ(下の表)をかける

**ウェーブと難易度(WaveSpawner)**

- 最初のウェーブは敵が 3 体。以降は、1 ウェーブごとに 2 体ずつ増える
- 空を飛ぶ敵は、ウェーブ 2 から出る(敵全体の 40%)
- 地上の敵の種類:
  - 俊敏:ウェーブ 2 から、地上の敵の 25%
  - 頑丈:ウェーブ 3 から、地上の敵の 25%
  - 巨大:ウェーブ 4 から、2 ウェーブごとに 1 体
- 敵は、1 つのウェーブの中で、約 8 秒かけて順番に出てくる。地上の敵は正面の 90〜120m 先、空の敵は 100〜140m 先から、遠くから近づいてくる(Editor の確認中は、左右 30 度の範囲。実機は 45 度)。出現したときは、0 から約 1.2 秒かけて、本来の大きさになる
- 遠くにいるあいだは、速く進む(到着までが長くなりすぎないため)。砦の手前 70m より遠いところでは、標準の速さの 2.5 倍(ただし、最低でも秒速 6m)で進み、30m から 70m の間で少しずつ本来の速さに戻る。到着までの目安は、標準のゴブリンで約 25 秒、俊敏で約 11 秒、頑丈で約 32 秒、巨大で約 42 秒、コウモリで約 14 秒
- 敵の大きさ(標準の敵):最初は標準の 1.2 倍。ウェーブが進むごとに 0.05 ずつ小さくなり、下限は 0.6 倍
- 地上の敵は、外柵の 0.9m 手前で止まる(大きい敵は、大きさに応じて、もう少し手前)
- 全部倒すと、3 秒後に次のウェーブが始まる
- 得点、ウェーブ、砦の耐久値、敵の大きさの表示は、プレイヤーの正面 4.5m、床から 1.8m の高さに浮かぶ。耐久値が 30% 以下になると赤くなる

**倒したときの演出(KillEffects)**

- 白からオレンジへ変わりながら、光の玉が広がる(約 0.2 秒)
- 敵の体の色をした破片が 16 個、四方へ飛び散って、落ちながら小さくなる
- 金色の得点(+10 など)が、上へ浮かんで、約 1 秒で消える
- 遠くの敵ほど、光と破片を大きくし(最大 2.4 倍)、数字も大きくする。巨大な敵を倒すと、演出も大きくなる

**銃が揃った状態の表現(R24。GunSystem の `UpdateLink`)**

- 「揃った」の条件は、両手撃ちの条件と同じ(2 丁の中心が 12cm 以内)。トリガーは関係ない。手が離れても 0.12 秒は「揃った」を保ち、境目でちらつかないようにする(両手撃ちの判定には影響しない)
- 起動から 3 秒間は判定しない(実機で、起動直後にコントローラーの位置が定まらず、2 つが重なって見えることがあるため)
- 揃った瞬間:音(金属の「カチッ」と、988Hz → 1480Hz の 2 音の鈴)、両コントローラーの短い振動(強さ 0.7、0.06 秒)、銃口の中点に水色の輪(12 個)と白い火花(8 個)、「LINK」の表示
- 揃っているあいだ:照準線が水色になり、太さが 0.008m 以上になる。先端の照準が、水色と白で脈打つ。左右の銃口を結ぶ光の橋(水色)と、真ん中の光の玉(大きさが脈打つ)
- 解除の瞬間:音(1800Hz から 300Hz へ下がる音と、息が抜けるような雑音)、弱い振動(強さ 0.35、0.04 秒)、オレンジの火花(10 個)、「SPLIT」の表示
- 揃っているあいだの銃の見た目(R25。VRGun の `UpdateLinkLook`。約 0.18 秒でなめらかに変わる):
  - 外側(左の銃は左、右の銃は右)に 12 度開いた羽根(暗い金属の板)
  - 銃身の両脇に、水色のレール(細長い箱)
  - 銃口の前(3cm)で、四角い枠(水色。1 秒に 200 度の速さで回る)。真ん中を照準の線が通る
  - 銃の上で、光るコア(水色と白で脈打つ小さな箱。ゆっくり回る)
  - 銃身が、グレードの色から水色へ、半分ほど混ざって光る
  - 解除すると、羽根などは消えて、銃身はグレードの色に戻る
  - 弾の出る位置(銃口)は、通常のまま
- 揃った状態で両手撃ちをしたあと、手がくっついたままなら、「揃った」は続く(解除の演出は出ない)

**ヘッドショット**

- 頭の当たり判定:ゴブリン系は、頭の位置に半径 0.33m の球(見た目の頭より少し大きめ)。コウモリは、頭の位置に半径 0.26m の球
- 体の当たり判定:ゴブリン系は、頭より下だけ(高さ 1.1m、半径 0.45m)。コウモリは、頭を含まない位置にずらした球(半径 0.6m)。以前より、真上から撃ったとき、体の判定が頭をふさがない
- 頭に当たると、体力に関係なく一撃で倒す。両手撃ちの太い弾でも同じ
- 演出(R23。倒したときの通常の演出に、次を足す):
  - 頭の位置に、大きな光の玉。金の火花 22 個と赤い火花 14 個が四方へ。プレイヤーのほうを向いた赤い輪(16 個)と、水平に広がる金の輪(16 個)。真上に噴き上がる火花 12 個。遠いほど大きくする(最大 2.6 倍)
  - 赤く大きな「HEADSHOT!」と得点(通常より 1.35 倍の大きさ、1.4 秒表示)。銃の上にも「HEADSHOT!」
  - 一瞬のスローモーション(`HitStop`。実時間 0.12 秒、時間の進みを 0.2 倍)。頭を動かしたときの見え方は、時間の進みの影響を受けないので、VR 酔いにはなりにくい
  - 音:高い 4 音の鈴に、短く重い破裂音と、光の走る音を重ねる
  - コントローラーが最大の強さで 0.2 秒震える
- 頑丈な敵(兜あり)は、兜の部分も頭の判定に含む。巨大な敵も、頭に当たれば一撃

**音(GameAudio。`WaveSpawner` の「音」の欄で、BGM の on/off と音量を調整できる)**

- 音のデータ(ファイル)は使わず、起動時に、数式で合成する(22050Hz、モノラル)。BGM は、起動後の数フレームをかけて、少しずつ作る
- 効果音は 3D の音(16 個の再生口を順番に使う)。近い音は大きく、120m で聞こえなくなる
- 銃声:チャージが小さいと高く軽い音、大きいと低く重い音。チャージ 0.5〜0.85 は、光の走る音を少しずつ足す。チャージ 0.85(約 1 秒)以上は、専用の派手な音(重い爆発、光の走る音、きらめき、反響)。両手撃ちは、さらに重い音に、光が走る音を重ねる
- ため撃ちの着弾:重い衝撃音(チャージ 0.4 割以上で、大きいほど大きな音)
- 弾切れ:「カチッ」。命中(倒れない)、撃破(通常:ポン / 巨大:低い爆発音)。アイテム(残弾:高い 2 音の鈴 / グレードアップ:上がる 4 音の鈴)
- 砦が攻撃されたときの低い音。ウェーブ開始:角笛。ウェーブクリア:鈴のフレーズ。ゲームオーバー:下がる角笛(このとき BGM は止まる)
- BGM:勇ましい行進曲風。128 BPM、ニ短調、16 小節(約 30 秒)のループ。和音は Dm → B♭ → C → Dm(4 小節ごとに繰り返す)。戦太鼓(1・3 拍目)、小太鼓(2・4 拍目、4 小節ごとに連打)、シンバル(4 小節の頭)、8 分音符で押す低音、ブラスのファンファーレ(1 オクターブ下を重ねて厚くし、後半は 5 度下も重ねる)。最後に軽く圧縮して迫力を出す。初期の音量は 0.35(効果音は 1)
- 聞く耳(AudioListener)は、頭のカメラに 1 つだけにする

**ため撃ちの派手さ(ShotEffects / ShotBurst)**

- 派手さ = 0(チャージ 4 割以下)〜 1(満タン)。大きいほど、下の演出が増える
- 銃口:光を大きくし、白い芯を足す。前へ扇状に飛ぶ火花(最大 20 個)と、衝撃波の輪(12 個)
- 弾道:太さ最大 2.2 倍、残る時間最大 1.8 倍(0.9 秒)、白っぽい色。派手さ 0.5 以上では、弾道に沿って輪が 3〜5 個、弾が通るタイミングで広がる
- 弾:太さ最大 2.2 倍、長さ最大 2 倍
- 着弾:光を最大 2.5 倍にし、四方への火花(最大 28 個)を足す。派手さ 0.5 以上で、衝撃波の輪も足す
- 火花や輪は、小さな箱の集まり(`ShotBurst`)。遠い場所ほど大きくする(距離による拡大は最大 3 倍)
- 撃った手の振動が、最大 0.2 秒長くなる
- 画面の揺れは入れない(VR 酔いを避けるため)

**頭の高さの補正(HeightCalibrator。実機のみ)**

- 目標:砦の床から目まで 1.6m(立っていても座っていても、同じ見え方にする)
- 起動の約 2 秒後に自動で補正する。頭の追跡がまだ始まっていないときは、最大 5 回まで試す。補正できたら、銃の上に「HEIGHT ADJUSTED」と出る(向きも 5 度より大きく回したときは「VIEW ADJUSTED」)
- 向きの補正(R29):そのとき頭が向いている方向を、砦の正面にする(リグを水平に回す)
- 両手のグリップを 1 秒押し続けると、高さと向きを補正し直す
- Editor の固定カメラでは使わない

**見た目(R26。`WaveSpawner` の「見た目」の欄で調整できる)**

- 空と光(`Atmosphere.cs`。R27 で真昼に変更):シーンの空を青空の色に変える(空の材質のファイルは書き換えず、複製を使う)。太陽は、方角 150 度(正面を 0、右が +。プレイヤーの後ろの右側)、高さ 55 度、ほぼ白(強さ 1.05)、影あり(Hard、濃さ 0.65)。正面に近づけると敵が逆光で暗くなる。環境光は 3 色(上:空色、横:明るい灰色、下:明るめの土色)。霧は、遠いほど濃くなる方式(ExponentialSquared)で、濃さ 0.0025、色はうすい青白。月と星は、星の数を 1 以上にしたときだけ出る(既定は 0)。夕暮れに戻したいときの目安:方角 50、高さ 13、星 45、霧 0.0045(色は `Atmosphere.cs` で変える)
- 模様(`ProcTex.cs`):石のレンガ、敷石、板、草、土を、起動時にプログラムで作る(128 ピクセル四方。画像ファイルは使わない)。材質は `PrimitiveMat` の複製に模様を掛けるだけで、新しいシェーダーは使わない(実機のピンク対策)
- 砦(`Fort.cs`):同じ色の飾りは、1 つの立体にまとめて描画を減らす(`MeshKit.cs`)。四隅の塔に円すいの屋根と、はためく旗。正面の壁に 2 枚のバナー(ゆっくり揺れる)。たいまつは 4 本(通路の左右 2 本と、正面の壁 2 本)。炎はゆらぎ、火の粉が昇る。暖色の点光源(強さ 2.4、届く距離 9m)は、R27 で既定を「切」にした(「たいまつの光を出す」で入る)。柵の内側にかがり火 2 本(炎だけ、光源なし)
- 景色(`Scenery.cs`):山 28 個(地平線をぐるりと囲む。正面の敵の城は、R28 で取り除いた)、木 最大 150 本(松と広葉樹。敵の通り道の扇形は避ける)、岩 60 個、茂み 70 個、草のかたまり 420 か所、光る青い水晶 16 群、道の縁石。すべて色ごとに 1 つの立体にまとめている
- 影:落とすのは、柵と、敵の影用の見えない立体(敵 1 体につき 1 つ。頭・胴・足・腕の形)だけ(R27 で、砦本体は影を落とさないことにした)。銃や火花などは、影を落とさない(`Paint.Apply` の既定を「影を落とさない」にした)。影は、カメラから 50m までの範囲だけ(URP の設定)
- 敵:目は 1 を超える明るい色にして光らせる。眉ときばを追加
- 銃(`VRGun.cs`):金の輪 2 つ、鉄の受け部と銃口の飾り、持ち手の革巻き、ルーンの宝石(ふだんは水色、チャージで金色に、撃った瞬間に白く、揃っているあいだは脈打つ)
- 文字(`HudText.cs`、`HudOutline.cs`):すべての文字に、黒いふち取りを付ける(同じ文字を 4 つ、ずらして後ろに置く)。ウェーブ表示は、見出しを金色、砦の耐久値を残りに応じて白か赤にする。文字の上に、砦の耐久値のバー(金の枠、緑から赤へ)を出す
- 重いときの調整順(Quest 2 で動きがカクつくとき):(1) 「太陽の影を出す」を切る (2) 霧の濃さを 0 にする(霧を切っても、ほぼ軽くならない)(たいまつの光は、既定で切ってある)。それでも重ければ、木や草の数を `Scenery.cs` で減らす

**表示**

- 各銃の上に、残弾(例:24/40)とグレードを表示する。残弾が 6 発以下になると赤くなる
- アイテムを取ると、「GRADE UP!」や「AMMO +8」の表示が、銃の上に一瞬出る

### 3.3 操作

**実機(Quest 2)**

- 左右のコントローラーの人差し指トリガーで、それぞれの銃を撃つ。銃は、それぞれのコントローラーの位置と向きに付く
- 両手撃ち:両手を近づけて、両方のトリガーを引いてから、どちらかを離す
- ゲームオーバーからの再開:両方のトリガーを 1 秒引き続ける
- 高さと向きの補正し直し:正面を向いて、両手のグリップ(横のボタン)を 1 秒引き続ける
- 武器の切り替え(R31、R32):銃口を頭上へ向けて(水平から 60 度以上)、0.1 秒保つ。その手の銃が、バズーカになる。もう一度同じことをすると、銃に戻る(切り替えたあとは、銃口を下げてから)。トリガーを引いている間は無効
- バズーカ:トリガーを引いた瞬間に 1 発。当たったとき、または敵の近くを通ったときに爆発して、まとめてダメージ。間隔は 1.5 秒

**Editor でのヘッドセットなしの確認(動作確認用の仮の操作)**

- マウスの左ボタン:右手の銃のトリガー
- マウスの右ボタン、または Z キー:左手の銃のトリガー(右クリックが効かない環境向けに、Z キーを用意した。Ken の環境では、右ボタンが反応しなかった)
- Space キーを押している間:左右の銃が中央に寄る(両手をくっつけた状態。中心の間隔 6cm)。ふだんは、左右に約 76cm 離れている
- 両手撃ち:Space を押したまま、左ボタンと Z キーを同時に押して、離す
- X キー:右手の武器を切り替える(「銃口を頭上へ向ける」の代わり)。C キー:左手の武器を切り替える。バズーカのときは、マウスの左ボタン(右手)/ 右ボタンまたは Z キー(左手)で撃つ
- 左右の矢印キー:テスト用のカメラを、水平に回す(毎秒 90 度。R34。全方向から敵が来る塔のステージを、見回して確認するため)
- 2 丁とも、マウスの指す点を向く(マウスが 1 つしかないため、別々の方向には向けられない)
- カメラは、目の高さ 1.6m に固定した専用のカメラを使う(ヘッドセットなしだと、カメラの位置が不安定になる現象があったため)。砦の壁の前にいる敵が見えるように、25 度下へ向け、視野を 75 度にしてある
- 左右を別々の方向に向けて確認したいときは、Meta XR Simulator を使う(4 章参照)

## 4. 未決定・要確認

- **敵の追加案(Ken に提案済み。どれを作るか未決定)**:
  - 盾持ち:正面の攻撃を防ぐ
  - 自爆ゴブリン:柵や砦に着くと爆発して、大ダメージ。手前で倒せば、演出だけ(Claude のおすすめ)
  - 治療師:近くの敵を回復する
  - スライム:倒すと、小さいスライムが 2 体に分かれる
  - コウモリの群れ:小さいコウモリが、まとまって飛んでくる(Claude のおすすめ)
  - ドラゴン(ボス):5 ウェーブごとに出る。火を吐くなら、「近接のみ」の要件を変える必要がある
  - 弓兵:遠くから撃ってくる。こちらも、「近接のみ」の要件を変える必要がある
- **Meta XR Simulator**:左右のコントローラーを別々に模擬できる公式ツール。Mac(Apple シリコン)に対応している。Unity 6.6 と Meta XR SDK 205 の今のプロジェクトで動くか、動いたときに私のコードが実機と同じ経路(左右のコントローラーを別々に読む経路)に切り替わるかは、未確認
- **遠くから来る敵の調整**:出現距離(90〜140m)、遠くでの速さ(2.5 倍、最低 6m/秒)、到着までの時間は、遊んでみて決める。遠すぎて敵が見えない、待ち時間が長い、と感じたら、`WaveSpawner` の「敵の出る位置」の欄で調整する。遠い敵は小さく見えるので、見つけやすくするために、霧や敵の目印を付ける案もある
- **ヘッドショットの調整**:追加得点(例:2 倍)を付けるか、巨大な敵は一撃にしないかなどは、実機で遊んでから決める。頭の判定の大きさも、狙いやすさを見て調整する(`Enemy.cs` の `AddHeadHitbox` の半径)
- **効果音・音楽**:実装済み(R18)。実際に聞いて、音量、音色、BGM の雰囲気を調整する。気に入らなければ、音のファイルへ差し替える方法もある
- **実機の見え方**:ピンク(R16)が直ったか、壁が画面の大半を占める問題が、座ったときに直ったか(R17)を、再ビルドして確認する。表示される EYE / ADJ / ORIGIN / MAT の値を教えてもらう
- **性能**:Quest 2 で、部品の数(標準の立体をたくさん使っている)と、色ごとに作る材質が、重くないか未確認。R26 で、影、たいまつの点光源(4 つ)、木・草・山などの飾りが増えたので、特に要確認(重ければ 3.2 章の「重いときの調整順」)
- **霧が実機で出るか(R26)**:霧の設定は、起動時にコードで入れているが、Unity のビルドは、シーンで霧が有効になっていないと、霧の処理をビルドから省くことがある。念のため、ビルドの前に、Unity の `Window > Rendering > Lighting > Environment` で、`Fog` にチェックを入れ、`Mode` を `Exponential Squared`、`Density` を `0.0025`、`Color` をうすい青白(R 184、G 209、B 240)にして、シーンを保存する
- **見た目の調整(R26)**:空の色、霧の色と濃さ、太陽の方角と高さなどは、Editor の Play(Game ビュー)で見ながら決める(色合いは、コードでは事前に確かめられないため、見た目を見て調整する)。雲は、のっぺりして見えるおそれがあるので、まだ入れていない
- **誰が遊ぶか**:自分だけで楽しむのか、他の人にも遊んでもらうのか(Ken に質問済み。未回答)。他の人が遊ぶなら、身長・姿勢の違いへの配慮を優先する
- **バランス**:ため撃ちと連打の損得、両手撃ちの倍率、ドロップ率、初期の残弾、砦の耐久値、敵の数・速さ・体力(特に、頑丈な敵と巨大な敵の体力)は、撃ち比べて決める
- **武器の切り替えと、バズーカ(R31、R32)**:実機で、(1) 銃口を頭上へ向けて、確実に切り替わるか、(2) 空の敵を狙うとき・ふつうに構えているときに、誤って切り替わらないか、(3) 爆発が、地面や敵の近くで期待どおりにダメージを与えるか、を確認する。切り替わりにくければ `skySwitchAngle`(60)を下げ、誤作動が多ければ `skySwitchAngle` を上げるか `skySwitchHold`(0.1)を長くする。近接信管の距離(`bazookaProximity` 1.5m)、威力(12)、範囲(3.5m)、間隔(1.5 秒)、残弾の消費(2 発)も、撃ち比べて決める
- **ステージ制と塔(R34)**:Unity でコンパイルが通るかを確認したうえで、(1) Editor で `startAtStage` を 2 にして、塔の見た目(左右の矢印キーで見回す)、(2) 通常どおり、ステージ 1 の WAVE 5 を全滅させて、塔へ切り替わるか(黒くなる演出、文字、残弾・グレードの持ち越し)、(3) 実機で、頂上から、外柵で止まった敵が見えて撃てるか(足場が視界を隠さないか、頭を下へ向ける角度がきつくないか)、(4) 方向マーカーが見やすいか・うるさくないか、(5) 全方向の敵の数・柵・景色で、Quest 2 が重くならないか(柵の杭は約 90 本を 1 つにまとめてある。重ければ、`castSunShadows` をオフ、景色の数を減らす、柵の杭を減らす)、(6) 塔の耐久値 120 と、柵で止まった敵の攻撃の強さのバランス、(7)(R35)WAVE 1〜5 で、敵が来る範囲が少しずつ広がっていくのが分かるか、最後の WAVE 5 の包囲が急すぎたり、逆に物足りなくないか、を確認する。広がり方は `towerOpeningHalfAngle` と `towerSurroundWave` で調整できる。塔を高くする・低くする、柵の半径、道の本数(24)、空の敵の飛ぶ半径も調整できる。頂上の真ん中で、`HeightCalibrator` の高さ補正が、塔でも合うかも確認する
- **敵の見つけやすさ(R37)**:実機で、(1) 砦・塔の両方で、地面と敵が見分けやすくなったか、(2) 地面が暗すぎて、雰囲気が沈んでいないか(`groundBrightness` を 0.5〜0.8 で調整)、(3) 足元の赤い輪が、目立ちすぎたり、邪魔になったりしないか、(4) 空の敵(コウモリ)が、地面を背景にしたときに見えるか、を確認する
- **中指のボタン(グリップ)の使い道(未決定)**:Ken に 5 つの案(必殺技、バレットタイム、弾種切り替えなど)を提案済み。銃口を頭上へ向けての武器切り替え(R31、R32)を入れたので、グリップは別の用途にできる。なお、今は、両手のグリップを 1 秒で高さと向きの補正し直しに使っている
- **両手撃ちの距離(12cm)**:実機で、手をくっつけたときに確実に発動し、離したときに誤って発動しないか確認する。発動しにくければ 0.15m くらいまで上げる(`GunSystem` の `comboDistance`)
- **砦の見え方**:砦を 6m にしたことで、外柵の前の敵が、実機で自然に見えて撃てるか確認する(R38 で柵を低くして、当たり判定をなくした。まだ視界の邪魔なら、`fortFenceHeight` を下げるか 0 にする)。低い壁の高さ、砦の高さ、外柵の位置を調整する可能性がある
- **実機での確認**:Quest 2 に Build And Run して確認できている。Mac(macOS 26)では `system_profiler SPUSBDataType` が何も出力しないため、認識の確認には `adb devices` か `ioreg -c IOUSBHostDevice -w0 | grep -i -E "quest|oculus|meta"` を使う
- **Editor の不具合**:ヘッドセットなしの Play で、カメラの高さが急に下がる現象があった。原因は特定していない(現在は固定カメラで回避している)。また、Meta の Interaction SDK が、Editor の Play 中に大量の NullReferenceException を出している(実機での挙動は未確認)
- **アプリ ID**:テンプレートの初期値(`com.UnityTechnologies.com.unity.template.urpblank`)のまま。変えるなら、早めに
- **Unity のバージョン**:6000.6.2f1(6.6)は、LTS かどうか未確認。問題が出たら、6.3 LTS へ切り替える
