# VRシューティング 要件まとめ(2026-09-20 時点)

Ken から伝えられた要望と、そこから決めた仕様を整理したものです。「Ken の要望」と「Claude が仮置きした値」を分けて書いています。仮置きの値は、実機で試してから調整する前提です。

## 1. ゲームの概要

- 一人称視点のVRシューティング
- 対象機種:Meta Quest 2 128GB
- 開発:Unity 6(6000.6.2f1)、Meta XR SDK 205.0、Mac mini(M4)
- 状況設定:プレイヤーは砦(とりで)の上に立って銃を構える。砦に向かって、地上と空中から敵が侵攻してくる。それを撃ち落として、砦を守る
- v1の遊び方:その場で立って撃つ(アリーナ型)。マルチプレイとストーリーは、v1ではやらない

## 3. 仕様の詳細

### 3.1 Ken が選んだこと

R5〜R7 について、次の選択肢を Ken が選びました。

- 両手撃ちの条件:両手を近づけて、両方のトリガーを引く(手の位置は問う。トリガーの同時押しだけでは発動しない)
- 残弾:両手で共有する(銃ごとに別々にはしない)
- アイテムの取得方法:自動で吸い寄せられる(倒した位置から、プレイヤーに向かって飛んでくる)
- グレード:両手で共通(片方だけ上がることはない)

R8〜R11 について、次の選択肢を Ken が選びました。

- ゲームオーバーの条件:砦に耐久値がある
- 敵の攻撃方法:近接のみ
- 砦や周囲の見た目:標準の立体で簡易に作る
- 世界観:中世ファンタジー(地上はゴブリン、空中はコウモリのような敵)

### 3.2 Claude が仮置きした値(実機で調整する)

すべて、Unity の Inspector から変更できます(砦・敵・ウェーブの値は、`Game` オブジェクトの `WaveSpawner`)。

**ため撃ち(GunSystem)**

- 威力:すぐ離すと 1、1.2 秒引き続けると最大の 5(その間は比例して増える)
- 撃ったあと、次のチャージを始められるまで 0.15 秒
- 弾は、銃口の向きへ、即座に届く方式(弾道の遅れはない)。射程は 120m
- 撃つと、その威力の大きさに応じて、コントローラーが震える。チャージ中も弱く震える
- チャージ中は、銃身の上のバーが伸び、照準線が太くオレンジになる

**両手撃ち(GunSystem)**

- 両手の距離が 25cm 以内のときに成立する
- 威力は、「2 丁ぶんの威力の合計 × 1.5」
- 残弾を 2 発ぶん使う。残弾が 1 発だけのときは、チャージの大きいほうの 1 丁だけで撃つ
- 弾は太く(半径 6cm)、当たりやすい
- 両手撃ちの状態になると、両方の銃の照準線が水色になる

**残弾(GunSystem)**

- 初期は 24 発、最大は 40 発
- 1 発撃つごとに 1 発減る。アイテム 1 個で 8 発回復する
- 詰まらないようにする決まり:
  - ウェーブが始まるとき、残弾が 10 発より少なければ、10 発まで補充する
  - 残弾が 0 のときは、3 秒ごとに 1 発だけ回復する
  - 残弾が 6 発以下のときに敵を倒すと、必ず残弾回復アイテムが出る

**グレード(GunSystem)**

- グレードは 1〜5。1 上がるごとに、威力が 30% 増える
- 銃身の色:1 が灰、2 が緑、3 が青、4 が紫、5 が金
- 最大グレードのときにグレードアップ品を取ると、残弾が回復する

**アイテムのドロップ**

- 敵を倒したときに、グレードアップ(金色の箱)が 35%、残弾回復(緑のカプセル)が 45%、何も出ないのが残りの 20%
- アイテムは、敵の胸の高さ(空中の敵はその位置)から、0.4 秒ほど浮かんだあと、プレイヤーの胸のあたりへ向かって加速しながら飛び、近づくと取得される。30 秒たつと消える

**砦(Fort)**

- 砦の高さは 3m。プレイヤーは、その上面(城壁の通路)の中央に立つ
- 砦の幅は約 9.6m。四隅に塔、正面の壁に木の門、左右と後ろに胸壁がある。正面は、真下の敵が見えて撃てるように、低い壁にしてある
- 耐久値は 100。敵が攻撃するたびに減る。減ったとき、砦が一瞬赤くなり、コントローラーが震える
- ウェーブをクリアするたびに、耐久値が 10 回復する
- 耐久値が 0 になるとゲームオーバー。画面に GAME OVER が出て、両方のトリガーを 1 秒引き続けると、最初からやり直す

**敵(Enemy / Target)**

- ゴブリン(地上):歩いて砦の壁の前まで来て、棍棒で殴る。体力 3、速さ 2.5m/秒、1 回の攻撃で砦に 3 ダメージ、攻撃の間隔 1.6 秒、倒すと 10 点
- コウモリ(空中):羽ばたいて砦の正面の空中まで飛んできて、急降下して攻撃する。体力 2、速さ 5m/秒、1 回の攻撃で砦に 2 ダメージ、攻撃の間隔 2 秒、倒すと 15 点
- 見た目は、標準の立体(球、カプセル、円柱、箱)を組み合わせて作る

**ウェーブと難易度(WaveSpawner)**

- 最初のウェーブは敵が 3 体。以降は、1 ウェーブごとに 2 体ずつ増える
- 空を飛ぶ敵は、ウェーブ 2 から出る(敵全体の 40%)
- 敵は、1 つのウェーブの中で、約 8 秒かけて順番に出てくる。地上の敵は正面の 30〜45m 先、空の敵は 35〜55m 先から来る(Editor の確認中は、左右 30 度の範囲。実機は 45 度)
- 敵の大きさ:最初は標準の 1.2 倍。ウェーブが進むごとに 0.05 ずつ小さくなり、下限は 0.6 倍
- 敵の速さは、1 ウェーブごとに 5% 増える。体力は、1 ウェーブごとに 8% 増える
- 全部倒すと、3 秒後に次のウェーブが始まる
- 得点、ウェーブ、砦の耐久値、敵の大きさの表示は、プレイヤーの正面 5m、高さ 2.2m の位置に浮かぶ。耐久値が 30% 以下になると赤くなる

**表示**

- 各銃の上に、残弾(例:24/40)とグレードを表示する。残弾が 6 発以下になると赤くなる
- アイテムを取ると、「GRADE UP!」や「AMMO +8」の表示が、銃の上に一瞬出る

### 3.3 操作

**実機(Quest 2)**

- 左右のコントローラーの人差し指トリガーで、それぞれの銃を撃つ
- 両手撃ち:両手を近づけて、両方のトリガーを引いてから、どちらかを離す
- ゲームオーバーからの再開:両方のトリガーを 1 秒引き続ける

**Editor でのヘッドセットなしの確認(動作確認用)**

- マウスの左ボタン:右手の銃のトリガー
- マウスの右ボタン:左手の銃のトリガー
- 左右のボタンを同時に押している間は、「両手が合わさっている」とみなす
- カメラは、目の高さ 1.6m に固定した専用のカメラを使う(ヘッドセットなしだと、カメラの位置が不安定になる現象があったため)。砦の壁の前にいる敵が見えるように、20 度下へ向け、視野を 75 度にしてある

## 4. 未決定・要確認

- **左の銃**:Ken から「左の銃が機能していない」との報告あり。どう機能しないのか(表示されない、撃てない、当たらない等)と、Console の `[VRGun]`・`[GunSystem]` の行を確認して、原因を調べる
- **敵の種類**:いまは、ゴブリンとコウモリの 2 種類のみ。遠距離攻撃をする敵、ボス、ドラゴンなどは、まだ決めていない
- **効果音・音楽**:未実装(銃声、命中音、アイテム取得音、砦が攻撃される音など)
- **バランス**:ため撃ちと連打の損得、両手撃ちの倍率、ドロップ率、初期の残弾、砦の耐久値、敵の数・速さ・体力は、撃ち比べて決める
- **両手撃ちの距離(25cm)**:実機で構えたときに、自然に発動する距離か確認する
- **砦の見え方**:壁の真下の敵が、実機で自然に見えて撃てるか(身を乗り出す前提でよいか)を確認する。低い壁の高さ、砦の高さ(3m)を調整する可能性がある
- **実機での確認**:Mac が Quest 2 を USB で認識しなくなり、現在は実機に出せない。ケーブルやポートの切り分けが途中。Wi-Fi 経由の ADB は、最初の 1 回は USB でつなぐ必要がある
- **Editor の不具合**:ヘッドセットなしの Play で、カメラの高さが急に下がる現象があった。原因は特定していない(現在は固定カメラで回避している)。また、Meta の Interaction SDK が、Editor の Play 中に大量の NullReferenceException を出している(実機での挙動は未確認)
- **アプリ ID**:テンプレートの初期値(`com.UnityTechnologies.com.unity.template.urpblank`)のまま。変えるなら、早めに
- **Unity のバージョン**:6000.6.2f1(6.6)は、LTS かどうか未確認。問題が出たら、6.3 LTS へ切り替える

## 5. 開発の進め方(Ken の希望)

- 説明は日本語で、画面での手順まで詳しく
- Git の commit と push は、Ken が自分の Terminal でコマンドを使って行う(GitHub Desktop は使わない)。リポジトリは `kenkawa/vr_game`
- C# スクリプトは Claude が `Assets/Scripts` に書き、Unity 上のオブジェクトの追加や設定、ビルドは Ken が行う
- 動作確認は、当面 Unity Editor で行う(マウスで操作)
- このファイル(`docs/requirements.md`)を正本とし、要望が増えるたびに更新する

## 6. 実装状況(`Assets/Scripts`)

| ファイル | 役割 |
|---|---|
| `GunSystem.cs` | 左右の銃の管理。ため撃ち、両手撃ち、残弾、グレード、ドロップ |
| `VRGun.cs` | 片手ぶんの銃。見た目、トリガーの読み取り、狙いの判定、表示、振動 |
| `Target.cs` | 撃たれる側の共通部分。体力、被弾の点滅、倒されたときの通知 |
| `Enemy.cs` | 敵(ゴブリン、コウモリ)。見た目の組み立て、砦への移動、攻撃 |
| `Fort.cs` | 砦。見た目の組み立て、耐久値、ダメージ、回復 |
| `WaveSpawner.cs` | ゲーム全体の流れ。砦の生成、ウェーブ、敵の出現、難易度、得点表示、ゲームオーバー |
| `ItemPickup.cs` | アイテム(グレードアップ、残弾回復) |
| `PlayerView.cs` | 頭・手・床の高さの窓口。Editor 用の固定カメラも作る |
| `HudText.cs` | 空間に浮かぶ文字を作る道具 |

Unity のシーン(`SampleScene`)では、空の GameObject `Game` に、`GunSystem` と `WaveSpawner` の 2 つを付ける(`GunSystem` がなくても、`WaveSpawner` が自動で追加する)。
